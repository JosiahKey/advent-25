# Advent of Code 2025 (Java)

My solutions to [Advent of Code 2025](https://adventofcode.com/2025) puzzles, written in Java.

Each solution includes the day's puzzle description as in-line comments, so you can read the problem alongside the code. The original puzzles are also archived on the Advent of Code website.

## Running a Solution

Each program reads the puzzle input from standard input:

```
javac Advent1.java
java Advent1 < input.txt
```

Puzzle inputs aren't included, since Advent of Code asks that they not be shared. Download your own from the site.
